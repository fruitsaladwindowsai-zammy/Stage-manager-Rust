# Keyboard Shortcuts & Gestures

Stage Manager supports global keyboard shortcuts, modifier clicks, and mouse edge triggers for lightning-fast window switching.

---

## 1. Global Keyboard Shortcuts

| Shortcut | Action | Description |
|---|---|---|
| `Win + \`` *(backtick)* | Toggle Sidebar | Slides the Stage Manager sidebar in or out. |
| `Alt + \`` *(backtick)* | Toggle Fallback | Automatic fallback if another utility reserves `Win + \``. |
| `Win + Alt + →` | Next Stage | Transitions smoothly to the next stage down the ribbon. |
| `Win + Alt + ←` | Previous Stage | Transitions smoothly to the previous stage up the ribbon. |
| `Win + Ctrl + →` | Next Virtual Desktop | Switches to the next Windows Virtual Desktop. |
| `Win + Ctrl + ←` | Previous Virtual Desktop | Switches to the previous Windows Virtual Desktop. |

---

## 2. Pointer & Click Modifiers

| Input | Target | Behavior |
|---|---|---|
| `Left Click` | Stage Card | Minimizes previous stage and activates selected stage. |
| `Shift + Left Click` | Stage Card | Merges the clicked application into your active stage. |
| `Hover` | Multi-Window Group | Horizontally fans out all windows in the group. |
| `Mouse Wheel` | Over Strip | Scrolls the stage carousel vertically. |
| `Hover Endpoint` | Screen Top/Bottom | Initiates continuous infinite scrolling. |
