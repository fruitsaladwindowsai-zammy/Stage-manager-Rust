Built for Performance & Elegance

Engineered specifically for Windows 10 & 11 using native Win32 hardware composition.

⚡

Live DWM Thumbnails

Links directly to the Windows Desktop Window Manager hardware compositor via DwmRegisterThumbnail. Zero CPU screenshot polling overhead.

🌊

VSync Spring Physics

Smooth, fluid motion governed by second-order damped spring dynamics paced to display vertical blank intervals (DwmFlush) for 60Hz and 120Hz refresh rates.

🗂️

Group Hover Fan-Out

Multi-window application stages fan out horizontally in real time when hovered, rendering individual Direct2D squircle icons for direct window targeting.

🖥️

Multi-Monitor Isolation

Each connected display runs its own independent stage strip, trigger sensor, and per-monitor DPI scaling, managing only windows located on that screen.

🪟

Virtual Desktop Aware

Integrates with the Windows IVirtualDesktopManager COM interface, isolating stage workspaces across Windows Virtual Desktops.

🪶

Sub-Megabyte Footprint

Compiles to a self-contained ~540 KB executable using under 20 MB of system RAM. Lives quietly in your Windows notification tray.

Install in 60 Seconds

winget install --id Git.Git -e --source winget; winget install --id Rustlang.Rustup -e --source winget

Keyboard Shortcuts & Controls

Quick reference for everyday stage navigation.

Shortcut / Input Action
Win + ` (or Alt + `) Toggle Stage Manager sidebar visibility
Move mouse to edge Smoothly reveal auto-hidden stage ribbon
Click stage card Switch active workspace to selected stage
Hover grouped stage Horizontally fan out individual windows in the group
Shift + Click stage Merge window into current active stage
Win + Alt + ← / → Cycle through stages sequentially
